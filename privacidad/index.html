Privacidad

Aviso de privacidad.

Información clara sobre los datos que recibe Farias Labs mediante este sitio.

Última actualización: 11 de agosto de 2026.

Responsable

Farias Labs es una marca comercial operada por Oscar Farías, prestador independiente en Chile. Para consultas sobre privacidad escribe a contacto@fariaslabs.cl.

Datos recopilados

El formulario puede recibir nombre, correo, empresa o proyecto, servicio de interés, urgencia, mensaje y página de origen. No se solicitan contraseñas, datos bancarios ni información especialmente sensible.

Finalidad

Los datos se utilizan para responder la solicitud, evaluar el posible servicio y mantener el seguimiento de esa conversación. No se venden ni se usan para campañas masivas sin consentimiento.

Proveedores técnicos

El sitio opera sobre Cloudflare Pages y el envío de correo puede utilizar proveedores técnicos configurados de forma segura. Estos proveedores procesan únicamente la información necesaria para prestar el servicio.

Conservación y eliminación

La información se conserva durante el tiempo necesario para responder y mantener el contexto comercial razonable. Puedes solicitar acceso, corrección o eliminación escribiendo al correo de contacto.

Seguridad

Farias Labs aplica HTTPS, gestión de secretos fuera del código, validación del formulario y controles de despliegue. Ningún sistema elimina por completo el riesgo; cualquier incidente relevante se evaluará y gestionará con transparencia.

Cambios

Este aviso puede actualizarse cuando cambien las herramientas o finalidades. La fecha visible indicará la versión vigente.
